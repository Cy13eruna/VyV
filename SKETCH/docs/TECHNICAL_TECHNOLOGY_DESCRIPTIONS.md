# ⚙️ TECHNICAL TECHNOLOGY DESCRIPTIONS

## Overview
Technology descriptions have been completely rewritten to be more technical, specific, and direct. The new descriptions focus on logical mechanics, precise values, and clear functionality rather than general explanations.

## Design Philosophy

### 1. Technical Precision
- **Specific Values**: All bonuses and costs include exact numbers
- **Clear Mechanics**: Precise action names and effects
- **Logical Structure**: Consistent format across all technologies
- **System Integration**: Descriptions reflect actual game mechanics

### 2. Concise Communication
- **Direct Language**: No unnecessary explanatory text
- **Bullet Points**: Easy-to-scan information structure
- **Action-Oriented**: Focus on what the technology does
- **Quantified Effects**: Measurable impacts and costs

### 3. Professional Terminology
- **Protocol/System Naming**: Technologies sound like advanced systems
- **Algorithm References**: Emphasizes computational nature
- **Optimization Focus**: Highlights efficiency improvements
- **Technical Accuracy**: Uses appropriate technical language

## Tier 1 Technologies (Implemented)

### 🚩 Settler → Territorial Expansion Protocol
```
Mechanics:
• Unit action: SETTLE → Creates new domain at unit position
• Cost: 1 power from unit's natal domain
• Result: New domain with level 1, 0 power
• Restriction: Requires available hex position
```

### 🧺 Harvest → Resource Optimization System
```
Mechanics:
• Domain upgrade: HARVEST → +1 power generation per turn
• Cost: Domain level × 1 power
• Effect: Permanent power generation increase
• Stacking: Multiple harvests compound effect
```

### ♥ Healer → Unit Restoration Protocol
```
Mechanics:
• Unit action: HEAL → Restores target unit health
• Range: Adjacent hexes only
• Target: Allied units with health < maximum
• Limitation: One heal per unit per turn
```

### 🗡 Fighter → Combat Efficiency Module
```
Mechanics:
• Unit action: ATTACK → Enhanced damage output
• Bonus: +25% base damage modifier
• Range: Standard combat range
• Effect: Applies to all unit combat interactions
```

### 🎣 Fish → Aquatic Resource Extraction
```
Mechanics:
• Domain upgrade: FISH → +2 power generation (coastal only)
• Cost: Domain level × 1 power
• Requirement: Domain adjacent to water hex
• Bonus: Higher yield than standard harvest
```

## Key Improvements

### 1. Quantified Effects
- **Before**: "Increases domain resource generation"
- **After**: "Domain upgrade: HARVEST → +1 power generation per turn"

### 2. Specific Costs
- **Before**: "Requires power"
- **After**: "Cost: Domain level × 1 power"

### 3. Clear Limitations
- **Before**: "Can heal allied units"
- **After**: "Range: Adjacent hexes only, Target: Allied units with health < maximum"

### 4. Precise Bonuses
- **Before**: "Enhanced damage"
- **After**: "Bonus: +25% base damage modifier"

## Technical Terminology

### Action Names
- **SETTLE**: Domain establishment
- **HARVEST/FISH**: Resource generation upgrades
- **HEAL/RITUAL**: Health restoration
- **ATTACK/CHARGE/VOLLEY**: Combat actions
- **SCOUT/HUNT**: Special abilities
- **EXCHANGE/PROTECT**: Advanced interactions

### System Names
- **Protocol**: Standardized procedures (Expansion, Restoration, Navigation)
- **System**: Integrated mechanisms (Optimization, Adaptation, Matrix)
- **Module**: Functional components (Combat Efficiency)
- **Network**: Connected systems (Economic Exchange)

### Measurement Units
- **Power**: Primary resource currency
- **Hexes**: Distance and area measurements
- **Percentage**: Bonus and penalty values
- **Turns**: Time-based limitations
- **Levels**: Progression indicators

## Benefits of Technical Descriptions

### 1. Clear Expectations
Players understand exactly what each technology provides without ambiguity

### 2. Strategic Planning
Precise values enable accurate cost-benefit analysis for research decisions

### 3. System Integration
Technical language reflects the game's mechanical nature

### 4. Professional Feel
Advanced terminology enhances the game's sophisticated atmosphere

### 5. Implementation Guidance
Detailed mechanics provide clear specifications for future development

## Consistency Standards

### Format Structure
1. **Title**: Technical system name
2. **Status**: Implementation status for Tier 2
3. **Brief**: One-line technical summary
4. **Mechanics**: Bulleted list of specific effects

### Value Presentation
- **Costs**: Always specify resource type and amount
- **Bonuses**: Include percentage or absolute values
- **Ranges**: Specify in hex units
- **Limitations**: Clear restrictions and requirements

### Language Style
- **Active Voice**: Direct action descriptions
- **Technical Terms**: Professional system terminology
- **Quantified Results**: Measurable outcomes
- **Logical Structure**: Cause-and-effect relationships

The technical descriptions significantly improve the technology system's clarity and professional presentation while providing precise information for strategic decision-making.
